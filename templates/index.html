How It Works

  1. Text Preprocessing: Cleans and normalizes article text
  2. Feature Extraction: Converts text to numerical features using TF-IDF
  3. ML Classification: Applies trained machine learning model
  4. Results: Shows prediction with confidence scores

ML Models Used

  • Random Forest
  • Support Vector Machine
  • Naive Bayes

Important Notes

  • Use as a tool, not definitive truth
