About TruthLens

Project Overview

TruthLens is an advanced article-level fake news classification system that leverages machine learning and natural language processing to identify potentially fake or misleading news articles.

Features

Text Preprocessing

Comprehensive cleaning, tokenization, lemmatization, and stopword removal

Feature Extraction

TF-IDF vectorization with n-gram support for advanced text analysis

Multiple ML Models

Logistic Regression, Random Forest, SVM, and Naive Bayes classifiers

Detailed Evaluation

Comprehensive metrics, confusion matrices, and ROC curves

How It Works

1

Data Collection

Training data from verified fake and real news sources

2

Preprocessing

Clean text, remove noise, normalize, and tokenize

3

Feature Engineering

Convert text to numerical features using TF-IDF

4

Model Training

Train multiple ML models and select the best performer

5

Prediction

Analyze new articles and provide confidence scores

Performance

Our system achieves strong performance on balanced datasets:

  • Logistic Regression: 85-90% accuracy (fast, interpretable)
  • Random Forest: 87-92% accuracy (robust, handles non-linearity)
  • SVM: 86-91% accuracy (excellent for high-dimensional data)
  • Naive Bayes: 82-87% accuracy (very fast baseline)

Performance varies based on dataset quality, size, and distribution.

Disclaimer

This system is designed for educational and research purposes. While it achieves good accuracy on test data, no automated system is perfect. Users should:

  • Use this as one tool among many for evaluating news credibility
  • Always verify information from multiple trusted sources
  • Consider the context, source reputation, and supporting evidence
  • Apply critical thinking when consuming news content

The predictions made by this system should not be considered definitive truth.
